# Stage 2 Evaluation — Step 2

This folder contains the ABox generation, SPARQL evaluation, and SHACL validation resources for Stage 2 of the CCO evaluation.

## Files

- `ABox and Sparql generation and evaluation.ipynb` — Jupyter notebook for generating ABox instances and SPARQL queries, and evaluating competency questions.
- `cco_shapes.ttl` — SHACL shapes file for validating ABox instances against CCO structural constraints
- `validation_results.csv` — Results of SHACL validation and SPARQL evaluation across all competency questions

## Folder

- `abox-sparql results/` — Contains the generated ABox instance data (TTL) and SPARQL competency question queries for each evaluated provision

## Namespaces

- CCO: `https://www.w3id.org/cco/cco#`
- ABox: `https://www.w3id.org/cco/abox#`
