# CCO-BFO Alignment

This ontology defines alignment mappings between the Core Compliance Ontology (CCO), the Basic Formal Ontology (BFO) as a foundational ontology, and related core ontologies such as the Normative Requirements Vocabulary (NRV). It also provides SKOS-based conceptual mappings to selected terms from LegalRuleML, LKIF, and FIBO.

## Files

- `CCO-BFO-Alignment.ttl, Alignment module that imports CCO and defines mapping axioms from CCO concepts to selected concepts in BFO, NRV, LegalRuleML, LKIF, and FIBO. It does not import or reproduce the full external ontologies.

## Usage

Open CCO-BFO-Alignment.ttl in Protégé. The module requires CCO (https://www.w3id.org/cco/cco) to be imported alongside this ontology. External ontology terms are referenced for alignment purposes only.
