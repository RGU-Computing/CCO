# CCO-BFO Alignment

This ontology defines formal alignments between the Core Compliance Ontology (CCO) and foundational ontologies including the Basic Formal Ontology (BFO) and the Normative Requirements Vocabulary (NRV), along with SKOS alignments to LegalRuleML, LKIF, and FIBO.

## Files

- `CCO-BFO-Alignment.ttl` — Alignment ontology that imports CCO and defines alignment axioms between CCO concepts and BFO, NRV, LegalRuleML, LKIF, and FIBO

## Usage

Open `CCO-BFO-Alignment.ttl` in Protégé. Requires CCO (`https://www.w3id.org/cco/cco`) to be imported alongside this ontology.
